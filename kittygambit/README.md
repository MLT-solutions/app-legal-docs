# Kitty Gambit

Kitty Gambit is a cozy focus timer built around a simple idea: staying focused can feel calmer when your timer has a small, charming world beside it.

The app pairs a Pomodoro-style timer with an ambient board scene, customizable companions, and background sounds. The long-term vision is to grow Kitty Gambit into a gentle focus companion with richer board moments, more companion personality, and more ways to make work or study sessions feel personal without becoming distracting.

Kitty Gambit is currently an **MVP release**. That means the first version focuses on the core experience: timer, ambient scene, companion choice, board style, and sound settings. More advanced features may come later after real user feedback.
