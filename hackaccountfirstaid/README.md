# Hacked Account First Aid for Windows

Hacked Account First Aid is a step-by-step Windows checklist for the hours after an account has been compromised — what to secure, in what order, and where each provider keeps the setting.

It is a checklist and a set of directions, not a security scanner. It does not scan your device, detect anything, or remove anything. If you need malware removal, use a product built for that.

The app is offline. There are no user accounts, no analytics, no advertising, no telemetry and no server of ours. It does not transmit your checklist activity or device data, and there is nothing to sign in to. What it stores — your progress and preferences — stays in its own Windows application-data folder.

It can open a website in your default browser, but only when you explicitly choose one: a service's settings page, the privacy policy, the terms, or the optional tip jar. Those sites are separate from the app and operate under their own privacy policies.
