# Comic Duplicate Scanner

Comic Duplicate Scanner finds duplicate comics and archives in your library — including the ones that are not byte-identical, where the same book has been saved twice at different sizes or in different formats.

It compares pages visually rather than by filename, so re-encoded and rescanned copies still match. Results are kept as scan sessions you can review before deciding what to remove, and a local hash cache makes repeat scans over the same library fast.

The app is **fully offline and local-only**. It does not collect, transmit or share any personal data, usage data, or file content — not file names, not paths, not the scan results themselves. Everything it creates, including the hash cache and session history, is an ordinary file on your own disk that you can move or delete at any time.

Available for Windows and Mac.
