# FolioBind: EPUB Studio

FolioBind: EPUB Studio turns documents and image archives you already have into
properly structured EPUB ebooks and provides a full EPUB metadata editor.

The supported source conversion formats are TXT, Markdown, DOCX, fixed-layout
PDF, CBZ, ZIP image archives, and CBR. Text references can be plain links,
Markdown images, HTML `<img>` tags, or BBCode
tags. Comic archives become image-first EPUBs, PDF becomes fixed-layout EPUB,
and DOCX becomes reflowable EPUB where supported.

Pictures can come from direct web links, from cloud share links pasted straight from the Share button, or from files already on your device. Chapters are detected automatically (第一章 / Chapter 1 / EP.1) and given a working table of contents, and a whole folder can be converted in one pass.

The app also keeps an eye on the books you have already made: it lists your library with image counts, file sizes and any pictures still pointing at the internet, and rebuilds a book to pull those in. Kindle and Mail delivery use Apple's system share and Mail tools; the app never asks for SMTP credentials.

You supply the files. The app ships no content, no catalogue and no sources of its own. It reads only the documents you point it at, and acts only on the references those documents already contain.

The interface is available in English, 简体中文, 繁體中文, 日本語, Español,
Français, Bahasa Indonesia, 한국어, Bahasa Melayu, Nederlands,
Português (BR) and Русский.
